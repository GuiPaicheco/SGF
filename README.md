# SGFS — Sistema de Gestão de Funcionários da Saúde

Aplicação web de apoio à organização de profissionais, calendários, férias e afastamentos de equipes de saúde.

## Proposta

Reunir informações de planejamento e facilitar a conferência dos períodos de ausência, com uma interface voltada às rotinas administrativas.

## Conhecer o projeto

- Consulte o código e o histórico para acompanhar a evolução.
- Para demonstrações, utilize exclusivamente dados fictícios.
- Acesso ao código não concede acesso a contas, registros ou ambientes operacionais.

## Desenvolvimento

A configuração de um ambiente de desenvolvimento deve ser feita pelo mantenedor responsável, com recursos isolados. Não utilize o ambiente operacional para experimentar mudanças.
