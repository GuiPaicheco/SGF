# Guia de homologação do SGFS

Roteiro para aceite institucional. Não representa aceite obtido nem autoriza escrever dados de teste em produção.

## Preparação

Registre versão/commit, data, ambiente, banco, equipamento, navegador e responsáveis RH/TI. Use ambiente isolado e dados fictícios; não copie documentos ou registros reais. Deixe os casos não executados explicitamente como pendentes.

## Casos

| Caso | Conferência esperada |
| --- | --- |
| Entrada | Início, login e simulação funcionam; nenhuma credencial gravada em evidências. |
| RH | Operador autorizado obrigatório; abas operacionais ocultas até a identificação. |
| Isolamento | RH não lê ou altera outra unidade; Administração consulta as unidades autorizadas. |
| CNES | Consulta sem gravação; diferenças conferidas antes de incorporar; resposta incompleta não apaga cadastros. |
| Integridade | Atualização preserva IDs, férias, folgas, autorias e remoções explícitas. |
| Operadores | Somente profissionais autorizados se identificam; revogação é revalidada pelo servidor. |
| Férias | Conferir regimes, período aquisitivo, fracionamento, dias úteis/corridos e férias-prêmio contra os casos normativos aprovados. |
| Folgas/afastamentos | Dias específicos, período com/sem retorno, alteração do retorno e cancelamento preservam autoria e histórico. |
| Day-off | Conferir aniversário, dias não úteis, recálculos e conflitos no mesmo vínculo. |
| Calendário | Mês/intervalo, filtros, critérios de conflito, formas nominal/longitudinal e colunas. |
| Feriados | Abrangência geral/específica e recálculo de férias conforme as validações do servidor. |
| Exportações | PDF A4 paisagem e XLSX legíveis no software institucional. |
| Acessibilidade | Teclado, foco, rótulos, zoom 200%, desktop e celular; rolagem sem corte da página. |
| Operação | Recuperação autorizada, política de acesso, backup e restauração isolada. |

Para cada caso: resultado esperado, obtido, evidência protegida, responsável, data e situação (aprovado/reprovado/não executado). Caso não executado nunca conta como aprovado.

## Regras e aceite
